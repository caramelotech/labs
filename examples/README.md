# Examples

Este diretório reúne exemplos genéricos usados pelo hub do Caramelo Labs.

## Como usar

1. Escolha um exemplo implementado
2. Leia o código e os comentários
3. Execute no ambiente indicado
4. Modifique e experimente variações

## Prática guiada

As sugestões de exercícios e projetos de cada trilha ficam nos repositórios dos labs, dentro de 
otes/pratica/, para que também apareçam no site publicado.

## hello-world

O exemplo mais simples possível: exibir uma mensagem na tela.

`	ext
imprimir("Olá, Caramelo Tech!")
`

Variações para praticar:

- Troque o texto pela sua própria mensagem
- Imprima várias linhas
- Combine texto com uma variável
